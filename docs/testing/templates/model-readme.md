# 厂家与完整型号

注册标识、物理通道和身份精确匹配规则；本目录是唯一维护源。

## 能力与协议

支持及未支持功能；官方资料标题、修订号、章节、链接；区分型号规格与当前固件证据。

按本包注册项和实际通道能力填写下表。“适用 / 不适用 / 待核对”描述型号能力，实测结论填在下方测试表。

| 项目 | 适用性及声明依据 | 本型号支持的范围或限制 |
| --- | --- | --- |
| 采集与保存 | 数据源、采集入口 | 单帧 / 连续 / 定时、通道、物理量、单位与轴 |
| 离线回放与导出 | `offline_processing` | 标量趋势或帧曲线、单位转换和导出形式 |
| MCP 能力查询 | 型号通道能力、可见数据源 | 预期通道、范围和数据源 |
| MCP 参数控制 | 可写操作及授权 | 读回或固件回执、恢复边界 |
| MCP 远程采集 | 支持的远程数据源及授权 | 采集方式、通道选择与结束条件 |
| MCP 远程指标 | `metric_profiles` | 处理项 ID 和版本、输入形态、指标单位 |

## 连接与驱动

型号接口、驱动位数/版本和连接要求。具体资产的可用接口与默认配置以运行目录为准。

列出 `deployment_components` 组件 ID、适用系统/接口、厂商安装材料和分发依据、检测方法、安装/重启/恢复要求与离线验证状态；引用公共组件清单，未知项标待补。串口/GPIB 记录实际适配器硬件 ID，网络需求包括 DHCP/静态地址及所需协议。

## 单位与限制

单位、静态/动态范围、关联状态、选件、错误与超时行为；不得默默钳位或重发命令。

## 桌面界面接入（适用时）

填写控制或监测入口、复用的同类面板和对应测试。列出本地显示参数、设备可写参数和回执来源。多角色型号注明各角色选择的物理通道、共享设置及影响。

## 文件与公共依赖

协议、范围、tests/fixtures、hardware 和离线记录转换器位置。禁止交叉导入其他型号。
