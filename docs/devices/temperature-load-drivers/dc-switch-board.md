# DC / CH3 / CH4 开关板

在设备管理总览点击“手动绑定开关板”，核对实际接线并选择 CP210x 串口。协议无查询命令。扫描、手动绑定、重新绑定和只读验收只核对系统枚举，不打开串口。首次确认控制命令才打开串口并写出。Windows 驱动开口时可能改变 DTR/RTS，板子可能复位；同一控制会话内沿用已开句柄。操作员指定板卡类型，USB 桥片标识用于筛选接口，板卡序列号留空。

## 能力与协议

设备管理的四个动作分别发送 `DC-on`、`DC-off`、`CH3-on` 和 `CH4-on`。每次确认后发送一条大小写固定的 ASCII 命令正文，无空格、换行或字节填充。CH3 和 CH4 由板端互斥，选择一路时另一条关闭。无独立 CH3-off 或 CH4-off 命令。

## 连接与范围

Windows CP210x VCP、VISA ASRL，115200 波特、8 数据位、无校验、1 停止位、无流控。实际 COM 号以当前枚举和接线为准。已有组件见[下载资源](../../generated/download-resources.md)。

## 测试与限制

管理页保留最近完整写出的命令，以及本机会话收到的原始字节（HEX 和可打印 ASCII）。命令后的短接收窗口最多 250 ms；晚到字节可在“状态与诊断”读取，单次最多读取 4096 字节。协议未定义回执语义，输出状态显示为未知。串口异常后需人工重新选择端口，写命令不自动重发。

型号包内离线用例覆盖绑定及重新绑定时串口零打开、零发送、四条命令和互斥选择。正式窗口已验证枚举、手动绑定、解除绑定和重新绑定，物理串口打开及命令发送次数均为零。实机只读验收见[硬件计划](../../../src/lab_control/instruments/devices/custom_dc_switch/hardware/README.md)，不涉及输出切换、测量或负载验证。
