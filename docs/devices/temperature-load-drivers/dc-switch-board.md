# DC / CH3 / CH4 开关板

扫描只枚举串口。点击“一键连接”后，软件向匹配的 CP210x 候选口发送一次 `*IDN?`（LF 结尾）；收到固件完整回复 `ESP32-S32 Board!` 才连接。也可手动选择端口。打开串口可能使 ESP32 复位并将输出置低。身份回复只含型号，USB 实例号用于跟踪端口。

## 能力与协议

| 点击操作 | 发送正文 | 固件确认行 |
| --- | --- | --- |
| 开启 DC | `dc_on` | DC已打开 |
| 关闭 DC | `dc_off` | DC已关闭 |
| 选择 RF3 | `ch3_on` | RF3已打开 |
| 选择 RF4 | `ch4_on` | RF4已打开 |

点击即发送一次。每条 ASCII 正文后附一个 LF（0A）。CH3、CH4 由固件互斥切换。自动化写操作继续使用项目的输出授权。连接和重连都核对身份后复用同一个串口会话。

## 连接与范围

Windows CP210x VCP、VISA ASRL，115200 波特、8 数据位、无校验、1 停止位、无流控。实际 COM 号随当前枚举确定。已有组件见[下载资源](../../generated/download-resources.md)。

## 测试与限制

首次打开串口后等待 1.5 秒让固件启动，再发送身份查询。页面下方的操作日志按时间追加每次点击的操作和结果，如“关闭 DC · DC已关闭”。同一窗口内按设备保留最近 200 条。完整写出但尚未收到匹配回执时显示“已发送”。状态页也以一句话显示最近操作，支持读取晚到的回执。发送后在设备工作线程上等待最多 2 秒，完整匹配即返回；中文回执行前的连续 0xFF 填充不影响识别。短写或写入异常显示“发送结果未知，请检查连接”。设备不会自动重发。固件收到未识别的命令会置低多个输出并打印“请输入命令”；该提示不能确认所请求的动作。固件没有独立的输出状态查询。
