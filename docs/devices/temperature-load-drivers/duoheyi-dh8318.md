# DUOHEYI DH-8318 八通道直流电子负载

注册标识为 `duoheyi.dh8318`，物理通道为 CH1～CH8。设备管理按通道设置负载，实时监测读取面板当前选择通道的平均电压和平均电流。

## 能力与协议

| 查询 | 仪器返回 | 软件用途 |
| --- | --- | --- |
| `*IDN?` | 厂家、型号、序列号和固件 | 用 `DUOHEYI,DH-8318` 匹配型号，用仪器序列号区分资产 |
| `CH?` | `ALL` 或单个通道号 | 将测量值对应到原始物理通道 |
| `MEAS:VOLT?` | 一个数值或一行逗号分隔的数值 | 平均电压，单位 V |
| `MEAS:CURR?` | 一个数值或一行逗号分隔的数值 | 平均电流，单位 A |

厂家随设备提供的《单通道、多通道可编程直流电子负载 用户使用手册》V1.1 第 11、19 页说明后面板接口及接线。第 22～24 页给出 ASCII 格式、身份查询和通道选择。第 27～28 页规定平均电压、电流的查询命令。命令和回包均以 LF（`0A`）结束。面板的“通信设置应答”控制设置命令的应答，读取测量值无需更改该项。

### 单通道输入控制

在「设备管理 → 电子负载 → 常用」选择 CH1～CH8 中的一路，点击对应设置的「应用」。第 24～26 页给出命令，第 7 页列出八通道机型规格。

| 控制 | 设置与回读 | 输入范围 |
| --- | --- | --- |
| 拉载开关 | `INP 1`、`INP 0`，`INP?` | 开、关 |
| 工作模式 | `MODE`、`MODE?` | CC 恒流、CV 恒压、CP 恒功率、CR 恒阻 |
| 恒流 | `CURR`、`CURR?` | 低量程 0～3 A，高量程 0～30 A |
| 恒压 | `VOLT`、`VOLT?` | 低量程 0～15 V，高量程 0～150 V |
| 恒功率 | `POW`、`POW?` | 每路 0～150 W |
| 恒阻 | `RES`、`RES?` | 0.05 Ω～50 kΩ |

写入前读取 `CH?`。原选择为 ALL 或其他单路时，软件临时选中目标通道并读回校验，操作后恢复原选择。设定值只写入当前模式，恒流和恒压会先查询当前档位。各设置单独生效，应用设定值不会顺带开启输入。设置应答启用时软件消费 `OK` 或 `ERR`，关闭时直接核对查询读回。若串口回包中断，界面提示重连并核对仪器状态。面板禁用“自动远程”时，应先进入远程模式。

## 连接与驱动

当前接入参数为 RS232、115200、8N1、无流控。后面板 RS232 接口通过交叉线接至电脑串口。使用 USB 转 RS232 适配器时，检查整条链路的收发线交叉关系。Windows 设备管理器中的 COM 号用于定位转接器，登记身份取自仪器的 `*IDN?`。

适配器使用项目已有的 `pyserial` 和 `serial-interface` 部署组件。Windows 按实际转接器的硬件 ID 选择驱动。适用芯片、安装和恢复步骤见[部署与环境修复](../../development/desktop-deployment.md)。

## 单位与限制

`ALL` 模式下每个查询应返回八个数值，顺序对应 CH1～CH8。在软件中选择其中几路时，按原通道号提取对应数值。单通道模式下，仪器返回一个数值，其通道号由 `CH?` 指定。采集过程中通道选择变化、不完整的回复或无效数值都会使本帧失效。实测为零时，保留仪器返回的零。

仪器依次响应电压和电流查询。两项读数来自同一有效通道选择，测量时刻可能略有差别。监测、保存和打开控制页均只查询。面板处于单通道选择时，其余通道的设置读数显示为不可用。
