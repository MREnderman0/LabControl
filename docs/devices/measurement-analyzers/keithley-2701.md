# Keithley 2701 / 7708 多路测量

## 能力与协议

在“实时监测 → 万用表”中默认使用仪器面板已有的扫描列表。可为指定主机和插卡绑定其中的四线 Pt100 测点。连接时查询主机身份、两个槽位的卡型和卡序列号。物理 7708 的测量输入为槽 1 的 101–140 和槽 2 的 201–240。继电器控制通道及无真实序列号的伪卡不能作为输入。

一次采集依次选择请求的物理通道，从连续转换中取新读数，核对仪器返回的通道号、单位和该路测量功能。记录保留每路的接收时间，80 路并非同时采样。整帧验证通过后可记录、回放和导出标量趋势。显式多通道请求也可从 Agent 的 reading 数据源采集；通道必须属于已授权的物理输入。当前适配未提供面板参数控制或远程指标。

## 连接与驱动

使用项目已有的 PyVISA 和 64 位 R&S VISA。首次使用给定 IP 和厂家端口创建 `TCPIP0::<IP>::1394::SOCKET` 资源；身份核验成功后，扫描可通过已登记的 LAN 主资源再次发现。设备身份使用主机序列号。适配器 ID 为 `keithley.2701`。

## 单位与限制

- 实机核验了直流电压（V）、四线电阻（Ω）及原生四线 Pt100 温度（°C）。协议解析也识别交流电压、二线及四线电阻、温度、频率和周期标签，其余测量功能须单独实测。
- 使用后面板、连续转换、立即触发和 ASCII 输出。为保留其他任务的现场，要求面板扫描和监视关闭、缓冲区未在存储、继电器全部打开。已有线路闭合时，监测暂停并显示仪器读回的通道。确认现场空闲、断开继电器后，可在原连接上重新开始监测。
- 仪器保持每路的原测量设置。采集时临时选择带通道号、单位的返回字段，结束或中途失败时释放测量路径，恢复原字段并读回核验。发现通道错位、过载、截断或配置变化时丢弃本帧；恢复失败须检查仪器并重新连接。
- 共用趋势图要求同一帧使用同一物理量和单位。插卡上的热电偶标识不能用作通道已配置为温度的依据。

## 四线 Pt100 测点

工作站将测点保存在当前设备的控制状态 `pt100` 中，包含主机 `serial`、按槽号保存的 7708 序列号 `cards` 和有序的主通道 `channels`。槽 1 可选 101–120，槽 2 可选 201–220；每路的感测通道为主通道加 20。连接时核对卡号和扫描列表，卡片更换或测点移出列表后须核对接线。未绑定的设备继续使用原有扫描列表。

采集时临时设置温度功能、四线 RTD、PT100 曲线和摄氏度，逐路核验主继电器、感测继电器、读数通道及摄氏度标签。过载或感测路径不符会丢弃该帧。采完打开继电器，并读回确认进入采集前的功能、传感器、曲线、单位和返回格式。通道名称属于工作站功能槽位，可在设备管理中编辑；监测与记录使用同一组名称。

## 测试入口与状态

软件回放覆盖两卡通道映射、新鲜读数、错误帧和恢复失败。运行 `python -m pytest src/lab_control/instruments/devices/keithley_2701/tests`。实机已验证两张 7708 的 80 路直流电压、记录回读、状态恢复、重连及已登记地址的再次发现。Agent 服务已按限定通道获取能力并保存整帧；数据处理已核对全部 80 路的通道、单位、数值和原始记录指纹。两卡四线 Pt100 已完成逐路原生摄氏度采集、记录回读和恢复核验，并抽取一路与四线电阻比对。绝对温度精度和热电偶须单独验收。见[实机计划](../../../src/lab_control/instruments/devices/keithley_2701/hardware/README.md)。

协议依据为 [2701 用户手册 §2、§3、§7、§14](https://download.tek.com/manual/2701-900-01G_Feb_2016.pdf)、[2701 网络手册](https://download.tek.com/manual/2701-904-01D_Feb_2016.pdf)及 [7708 卡手册](https://www.tek.com/en/keithley-switching-and-data-acquisition-systems/keithley-2700-multimeter-data-acquisition-switch-4)。
