# NI 9230 (BNC) 三通道加速度监测

## 连接与驱动

通过 NI-DAQmx 26.8 x64 和 USB cDAQ 机箱发现实际 NI 9230 (BNC) 模块。连接按模块序列号核对身份。发现、连接、打开页面只读取元数据。

## 界面接入

从“测量分析”进入“加速度采集”。页面沿用光功率计的监测交互，左侧显示趋势，右侧显示各路的当前读数与输入状态。CH1、CH2、CH3 分别对应 AI0、AI1、AI2；轴向由现场安装决定。

## 实时监测与记录

选择输入与刷新间隔，点“开始监测”。每路独立检查上电后的基线，稳定一路就显示一路。检查使用最近两段连续的一秒原始数据。两段的有符号均值都在 ±0.0005 g 内、均值之差不超过 0.00025 g，且窗口内未越量程、输入无故障时通过。强低频运动也会改变窗口均值，可能推迟首次显示。检查只在启动和输入故障恢复时进行。

每次刷新读取一个新的同步扫描点，显示和记录已稳定输入的瞬时加速度，单位 g。趋势按软件读取时间绘制。“开始记录”逐帧保存；停止记录后继续显示。停止监测时将所选输入的激励设为 0 mA，核对驱动读回并释放任务。等待稳定期间也可停止。

| 参数 | 范围或行为 |
| --- | --- |
| 传感器 | CT12000L，标称 20,000 mV/g，±0.25 g |
| 输入 | AC 耦合，内部 IEPE 4 mA；动态加速度 |
| 采样 | 模块内部以 3,200 S/s 同步采样；页面与记录按设定间隔取最新一个点 |
| 输入故障 | 单路开路、过流或超量程时显示状态，记录仅包含健康通道的数值；全部异常时等待有效输入 |
| 停止及重启 | 停止监测时显式关闭所选输入的激励；下次启动按各路实测基线判断 |

监测点适合查看瞬时读数与趋势。波形频谱、振动峰值与窗口 RMS 需要相应的连续原始样本。历史波形文件仍可离线回放。每次刷新等待一个新的同步扫描点，记录输入状态、灵敏度、物理通道及硬件采样序号。

## 灵敏度与测试

资产选项 `ct12000l.all=数值` 设置三路共用灵敏度，单位 mV/g。逐只绑定使用 `ct12000l.ai0=传感器序列号@数值` 等选项，两种方式互斥。未指定的输入使用标称值，记录中注明灵敏度来源。绝对量值精度需用外部标准另验。
