# 石墨版监视列表记录与趋势回看

2026-11-27，在带有本地 0.3.1 设置和读数格式的石墨工作区中，使用模拟 Keithley 2701 温度通道和单独的临时数据目录完成桌面验收。覆盖监视列表主页面、记录状态以及读取 SQLite 批次的独立趋势窗口。

| 场景 | 核对内容 | 截图 |
| --- | --- | --- |
| 空预设 | 保留添加监视量入口，开始记录按钮禁用 | [空预设](../../design/reviews/watch-recording/empty-1440x900-1.png) |
| 正在记录 | 主表显示当前值、单位、上下限、更新时间、状态和已写点数。窄窗口中预设移至表格上方 | [1280×760，150%](../../design/reviews/watch-recording/recording-1280x760-1.5.png) |
| 历史回看 | 按批次显示已完成记录，图表使用采集时间和该项单位 | [已完成批次](../../design/reviews/watch-recording/history-1440x900-1.25.png) |
| 上次记录中断 | 历史选择器显示中断状态，仍能读取已提交样本 | [中断批次](../../design/reviews/watch-recording/interrupted-1280x760-1.png) |

每种状态分别按 1280×760 和 1440×900 物理分辨率、100%、125% 和 150% 缩放离屏渲染。检查主操作与读数的位置、控件重叠和表格横向滚动。历史与中断样本通过正式批次存储接口生成。各张截图的物理尺寸、缩放和控件坐标见[验收数据](../../design/reviews/watch-recording/metrics.json)。

交互回归覆盖主窗口和独立窗口共用一个记录批次、离开页面后继续写入、正常退出时完成 CSV、在记录结束后保留选中的历史批次，以及将当前视野导出为 PNG 和按点击时刻导出所选行的完整 CSV。实际操作见[控制与监测指南](../guides/control-and-monitoring.md)。
