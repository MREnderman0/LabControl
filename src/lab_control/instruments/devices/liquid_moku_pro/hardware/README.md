# Moku:Pro 硬件计划

## 目标与授权范围

只对指定序列号核验。仅允许信号源 ch1 经物理线送到示波器 ch1 和频谱仪 ch1。其他通道不发信号。

## 前置条件与备份

[只读入口](preflight.py) 的 `--resource` 与 `--serial` 必填；可加 `--workspace` 用正式分类卡片只读打开三个面板，在批次中保存截图。核对运行路径、占用锁、REST 身份、固件；无控制权无法读取槽位时记录受阻，不推断当前模式。输出前确认接线、无分支、实际 50 Ω 负载、增益、原配置可恢复、全部四路实际输出状态。保留配置文件、哈希、路由、槽位、前端、各通道初始参数。第四槽和相关 bitstream 不能恢复则阻止写入。

## 测试矩阵

默认预检只读身份。要检查已登记四槽模式的资产，增加 `--verify-four-slot`。它通过项目适配器建立非强制会话，选择四槽模式，核对槽号，并在结束时释放会话。未建立会话就读取 `mim/get_instruments` 时，MokuOS 4.4 可能返回 `NETWORK_ERROR`；取到所有权后仍需在该会话选择四槽。

| 项目 | 方法与证据 |
|---|---|
| 枚举 / 身份 / 连接 | 枚举、只读身份、非强制控制会话分开记录。|
| 参数与物理测量 | 确认 0 dB、100 mVpp、零偏置；10 kHz 和 20 kHz 各采多帧；比较周期 100 µs 和 50 µs、Vpp 与频谱主峰。事先按时基、采样间隔、RBW 与负载约定容差。关输出后记录对照，不替代独立校准。|
| 采集 / 保存 / 回放 | 两路逐帧记录，停止其中一路后另一路继续；按帧编号、角色、通道、单位和代表点复核导出。|
| 恢复 / 重连 | 对照初态恢复四槽、前端、路由、输出和各槽参数，重连再读。|

## 停止与恢复

忙、固件不符、备份不足、负载不清均停在只读。写超时不重发，不推断最终状态，不恢复出厂。未知项逐一留档。

## 交付与未测

批次在运行目录保留 `results.json`、`summary.json` 和 `record.md`，由公共维护器更新索引。软件选通不是 ch2、ch3、ch4 的实机验收。
