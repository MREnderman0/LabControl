# WaveRunner 8254M 实机验收

## 目标与条件

针对配置文件指定的单一资源，核对完整型号和预期序列号。在当前面板接口、通道和输入条件下验证连接、三次重连、被动采集与落盘。TCP/IP 面板选择 VICP；LXI 面板选择 VISA/VXI-11。不同接口分别留档。使用项目正式运行目录、进程锁及设备会话。

## 执行与判定

运行 `python -m lab_control.instruments.devices.lecroy_waverunner8254m.hardware.readonly --config <单设备配置文件>`。也可使用公共 `verify-readonly` 入口。允许的查询在型号 profile 和 `readonly.QUERIES`。

1. 定向发现，校验身份，连接并记录通道、显示刻度、时基、触发模式及传输格式。
2. 断开重连三次，逐次比较身份和参数快照。
3. 获取所有已开启的模拟通道，核对回包来源、长度、点数、单位和单调时轴。沿用仪器上的传输设置。
4. 通过公共分段存储写入并重新打开，逐点比较原始值、时间、单位和通道。保存通信、二进制回复和数据文件，区分只读实机证据与离线回放。
5. 接口警告、超时、截断、设置变化或身份冲突均停止该次验收，记录错误与最后已知状态。释放会话，生成结果、摘要及资产索引。

## 参数控制与 Single

运行 `python -m lab_control.instruments.devices.lecroy_waverunner8254m.hardware.control --resource <已登记的 VICP 地址> --serial <完整序列号> --channel <已开启的模拟通道号>`，输入应具有可触发的边沿。该命令使用正式硬件锁和设备工作线程，覆盖当前测试通道和整机参数。仪器处于模拟边沿触发、至少两个通道已开启时，可验证触发源切换。

写入前保存完整面板 `PNSU?` 原始块、通信设置和各通道查询结果。参数经正式控制接口写入后再独立查询。两次 Single 分别验证停在本次波形及恢复连续采集，按描述符触发时间区分新旧波形，写盘后逐点比对。收尾时按原始面板恢复并再次读取所有快照字段和完整面板。面板哈希比较仅排除 MAUI 在导出时生成的时间注释。差异、失败和实际结果保存在运行目录对应批次。

## 只读验收范围

本入口不启动触发，不写面板、输入通道或输出。参数恢复和物理精度在此批次列为未测。离线回放及按通道导出可另行从保存的实机记录验证；MCP 权限查询与远程采集单列，不用本地采集结论代替。
