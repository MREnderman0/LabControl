# 自制开关板只读验收

以现场确认的 CP210x COM 口运行 `verify-readonly`，选择 `custom.dc_switch`、`visa` 和人工资产号下的独立批次。启动过程中占用正式设备锁。系统枚举、人工选口、解除绑定和重新绑定分别留档。只读入口拒绝打开任何物理串口；记录打开尝试次数。审计导出 `results.json`、`summary.json` 和 `communication.jsonl`；原始 USB 标识保存在运行目录。

本协议仅有四个输出动作，没有身份、测量或开关状态查询。驱动打开串口时可能改变 DTR/RTS，引起板卡复位。仅在确认输出操作时才打开串口。实际开关与互斥效果需要另行进行输出验收。遵循[实机记录规范](../../../../../../docs/testing/records.md)。
