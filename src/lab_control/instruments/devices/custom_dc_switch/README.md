# DC / CH3 / CH4 开关板

在设备管理总览点击“手动绑定开关板”，选择接有板卡的 CP210x 串口。扫描、绑定和重新绑定仅使用系统枚举。首次点击输出按钮时打开串口，开口时 DTR/RTS 变化可能使板卡复位。USB 标识用于筛选接口，板卡序列号由资产登记。

## 能力与协议

| 点击操作 | 发送正文 | 固件确认行 |
| --- | --- | --- |
| 开启 DC | `dc_on` | DC已打开 |
| 关闭 DC | `dc_off` | DC已关闭 |
| 选择 RF3 | `ch3_on` | RF3已打开 |
| 选择 RF4 | `ch4_on` | RF4已打开 |

点击即发送一次。每条 ASCII 正文后附一个 LF（0A）。CH3、CH4 由固件互斥切换。自动化写操作继续使用项目的输出授权。固件还提供身份查询，绑定流程使用系统枚举以免开串口复位。

## 连接与范围

Windows CP210x VCP、VISA ASRL，115200 波特、8 数据位、无校验、1 停止位、无流控。实际 COM 号随当前枚举确定。已有组件见[下载资源](../../../../../docs/generated/download-resources.md)。

## 测试与限制

首次打开串口后等待 1.5 秒让固件启动，再发送用户点击的命令。页面下方的操作日志按时间追加每次点击的操作和结果，如“关闭 DC · DC已关闭”。同一窗口内按设备保留最近 200 条。完整写出但尚未收到匹配回执时显示“已发送”。状态页也以一句话显示最近操作，支持读取晚到的回执。发送后在设备工作线程上等待最多 2 秒，完整匹配即返回；中文回执行前的连续 0xFF 填充不影响识别。短写或写入异常显示“发送结果未知，请检查连接”。设备不会自动重发。固件收到未识别的命令会置低多个输出并打印“请输入命令”；该提示不能确认所请求的动作。固件没有独立的输出状态查询。

[实机计划](hardware/README.md)区分只读绑定、主动输出和外部物理测量。按资产保留原始通信、结果和摘要。
