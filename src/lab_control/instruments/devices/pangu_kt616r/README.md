# 盘古 KT616R

## 能力与协议

KT616R 是 16 路无纸记录仪。有线端口使用 Modbus TCP，功能码 04。协议依据为 [KT600 系列使用手册，第 13.5、13.6 节](https://en.pangu.com.hk/download/manual/KT600_EN.pdf)。设备持续自行测量，软件只读当前输入。多通道监测、趋势和记录使用共享扫描列表页面。

## 连接与驱动

在设备地址管理中选择盘古 KT616R，填入仪表 IP，端口默认 502，可选择仪器网卡。运行时使用 Python 标准库和系统 TCP/IP，无需单独安装驱动。仅探测明确保存的端点。连接核对 16 个整数寄存器和 32 个浮点寄存器的响应格式。该检查不能提供序列号或区分其他采用同一映射的仪器。

## 范围与约束

- 默认站号 1，使用 30001–30016 的有符号整数，单位为原始计数，小数位由仪表组态决定。每帧读取整个寄存器块。
- 连接时从 16 路读回值建立监测列表，跳过具有现场空载特征的通道。全部空载时，页面保留 16 路位置，采集暂停。接线后重新连接即可刷新列表。配置文件的 `options` 也可指定 `station=1` 和固定通道，例如 `channels=1,2`。
- 30101–30132 为 16 个 IEEE 754 浮点数。面板字节顺序核对后才设置 `float_order=ABCD`、`BADC`、`CDAB` 或 `DCBA`，字母表示线上四个字节相对 IEEE 大端形式的位置。要使用温度趋势，核对所选通道采用同一面板单位后，再设置例如 `unit=°C`。未配置温度单位时不会产生温度指标。
- 现场无传感器时曾同时返回整数 `0x8080` 和浮点约 `−326.4`。保守拒收所选通道中出现此特征的帧。该判据可能同时屏蔽相同数值的有效输入，尚未确认是厂家通用断线编码。原始数保留在状态与实机通信记录。
- 控制和输出功能未开放。型号、序列号和量值准确性需现场核对。
