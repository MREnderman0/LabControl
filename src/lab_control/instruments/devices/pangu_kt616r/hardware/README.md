# KT616R 以太网实机计划

1. 核对仪器面板、静态地址、站号及当前接线。序列号未知时分配独立的待核对资产目录。地址不作为序列号。
2. 用项目 CLI 的 `verify-readonly` 指定配置、适配器和唯一端点。新建独立批次，通过正式运行目录的全局锁和设备会话执行，遇到占用即留档退出。
3. 读取 30001–30016 和 30101–30132；核查站号、事务号、长度、通道顺序。重复采集并关闭、重连。发送及返回字节记入 communication.jsonl。空载特征阻止生成测量帧。
4. 现场有传感器后另建批次，记录型号、通道、单位、面板读数、字序、参考仪表和预先约定的容差。核对至少两个不同读数及监测记录。当前只读测试不涉及参数恢复或输出使能。
