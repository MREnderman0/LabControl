# 4959E 只读验收

配置文件选择一台实际 LAN VISA 资源，适配器填写 `ceyear.4959e`，预期序列号来自本次发现记录。运行 `python -m lab_control.instruments.devices.ceyear_4959e.hardware.readonly --config <单台配置文件>`，将由正式运行目录保存原始通信、身份、参数、采集结果和重连记录。配置文件及原始回包保存在资产运行目录。

在面板选择 SA、线性扫描并显示 Trace 1。轨迹可以来自现有输入或仪器本底。记录接线或已知参考信号条件。线性扫描核对起止频率、点数、dBm 和频率轴，零扫宽核对秒轴与实际扫时。标准检波返回双倍幅值时，核对所有原始样本、dBm 单位和传输样本序号，另记仪器扫描点数和实收幅值数。曲线和坐标均可与面板交叉检查。

身份、模式、传输格式、扫频方式、轨迹类型、点数或数据长度出现异常时记录失败原因。判定连接与迹线读取通过所需的条件包括返回匹配的序列号、采集到完整有效的帧、重连后身份和配置一致。控制命令和恢复须另建批次，物理精度需记录可溯源的输入条件。
