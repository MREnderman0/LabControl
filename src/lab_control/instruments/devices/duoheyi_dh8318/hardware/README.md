# DH-8318 只读实机验收

## 目标与授权范围

核对一台 DUOHEYI DH-8318 的身份、已选通道平均电压和平均电流。现场配置记录串口、预期序列号、固件、接线和负载条件。测试使用面板已有状态。若需验证带载精度，应单独安排已知输入并记录参考表读数。

## 前置条件与备份

确认 RS232 链路交叉、面板波特率 115200，Windows 已枚举目标串口。配置文件仅列目标仪器，适配器为 `duoheyi.dh8318`，传输为 `serial`，并填入仪器的预期序列号。协议使用 8N1、无流控、LF。实机测试使用正式运行目录与项目进程锁。若需要中断监测，先记下活动设备、通道及采样间隔。

## 测试矩阵

| 项目 | 操作 | 预期与归档 |
| --- | --- | --- |
| 身份 | 查询 `*IDN?` | 厂家和型号匹配，序列号与本次选择的资产一致 |
| 选通状态 | 查询 `CH?` | `ALL` 或一个有效物理通道号，记录原回复 |
| 电压、电流 | 顺次查询 `MEAS:VOLT?` 与 `MEAS:CURR?` | `ALL` 的每个回复有八个有限数值，单通道各有一个。按原通道和 V、A 分别保存 |
| 保存与回读 | 将测量帧存入项目记录，再重新打开 | 校验测量量、通道、单位及每个数值，与原帧逐项一致 |
| 重连 | 释放后经型号工厂重新打开 | 核对同一身份与通道选择 |
| 正式界面 | 用 `run.bat` 启动后选择电子负载 | 确认连接、实时电压电流及显示通道，记录对应批次 |

项目 Python 运行以下显式入口，替换配置路径即可。每次创建一个独立批次。

```powershell
python -m lab_control.instruments.devices.duoheyi_dh8318.hardware.verify --config "<单台仪器配置.json>"
```

## 停止与恢复

身份不符、选择改变、超时、数据截断或数量不符时，记录错误和原始通信，停止本次验收。测试只发送四种查询。结束时释放串口，按现场安排恢复原有软件监测。负载物理输出状态和实测精度分别记录。

## 交付与未测

批次内保存 `results.json`、`summary.json`、`record.md` 和 `communication.jsonl`，成功采集的测量帧另存为可回读记录。由公共维护器更新资产索引。面板只处于一种通道选择时，记录该状态的证据，另一状态保留待验。现场零读数可以验证通信与数据保存，非零读数和物理精度需要相应输入条件。

## 单通道控制实机补验

离线回归覆盖单路和 ALL 两种初始选择、设置应答开关、四种模式、各设定值、输入开关、通道恢复及写后回读失败。上述测试使用串口替身。待安排已知电源和负载条件后，为实机控制另建批次。先记录目标通道的原模式、各设定值、输入状态及原通道选择。逐项读回，核对其他通道未变化，恢复后再分别记录仪器读回与外部测量结果。
