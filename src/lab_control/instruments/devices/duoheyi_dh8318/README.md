# DUOHEYI DH-8318 八通道直流电子负载

注册标识为 `duoheyi.dh8318`，物理通道为 CH1～CH8。软件读取仪器当前选择通道的平均电压和平均电流。

## 能力与协议

| 查询 | 仪器返回 | 软件用途 |
| --- | --- | --- |
| `*IDN?` | 厂家、型号、序列号和固件 | 用 `DUOHEYI,DH-8318` 匹配型号，用仪器序列号区分资产 |
| `CH?` | `ALL` 或单个通道号 | 将测量值对应到原始物理通道 |
| `MEAS:VOLT?` | 一个数值或一行逗号分隔的数值 | 平均电压，单位 V |
| `MEAS:CURR?` | 一个数值或一行逗号分隔的数值 | 平均电流，单位 A |

厂家随设备提供的《单通道、多通道可编程直流电子负载 用户使用手册》V1.1 第 11、19 页说明后面板接口及接线。第 22～24 页给出 ASCII 格式、身份查询和通道选择。第 27～28 页规定平均电压、电流的查询命令。命令和回包均以 LF（`0A`）结束。面板的“通信设置应答”控制设置命令的应答，读取测量值无需更改该项。

## 连接与驱动

当前接入参数为 RS232、115200、8N1、无流控。后面板 RS232 接口通过交叉线接至电脑串口。使用 USB 转 RS232 适配器时，检查整条链路的收发线交叉关系。Windows 设备管理器中的 COM 号用于定位转接器，登记身份取自仪器的 `*IDN?`。

适配器使用项目已有的 `pyserial` 和 `serial-interface` 部署组件。Windows 按实际转接器的硬件 ID 选择驱动。适用芯片、安装和恢复步骤见[部署与环境修复](../../../../../docs/development/desktop-deployment.md)。

## 单位与限制

`ALL` 模式下每个查询应返回八个数值，顺序对应 CH1～CH8。在软件中选择其中几路时，按原通道号提取对应数值。单通道模式下，仪器返回一个数值，其通道号由 `CH?` 指定。采集过程中通道选择变化、不完整的回复或无效数值都会使本帧失效。实测为零时，保留仪器返回的零。

仪器依次响应电压和电流查询。两项读数来自同一有效通道选择，测量时刻可能略有差别。接入范围为只读测量，负载设定、电流注入和物理精度另行验收。

## 文件与公共依赖

`tests/` 存放脱敏协议回归。[只读实机计划](hardware/README.md)说明台账、保存回读与重连验证。型号包使用公共串口传输、会话、采集与记录接口。

## 测试入口与实机状态

| 功能 | 接口及条件 | 验证范围 |
| --- | --- | --- |
| 型号、序列号、固件 | RS232 交叉线，115200 | 两次打开串口，均读回相同的四字段身份 |
| 八路平均电压和电流 | `CH? = ALL`，固件 `VER:23C/16C` | 两次读取均返回八路电压、八路电流，现场读数均为零 |
| 正式软件接入 | `run.bat`，按序列号连接 | 各次连接、采集及重连的验收结果见运行目录的资产批次 |

软件回归运行 `python -m pytest src/lab_control/instruments/devices/duoheyi_dh8318/tests`。实际仪器身份、采样和通信记录保存在当前电脑的 `hardware-tests` 目录。

## 已知限制与待测

实机单通道选择和非零输入下的读数待验。电压、电流的物理精度须在已知负载和可溯源参考表条件下验证。
