# Keithley 2701 实机核验

固定目标为操作者选定的 2701 主机和 7708 物理测量输入。先核对主机型号、序列号及实验网口，并确认项目实机锁可用。具体地址、序列号、接线和实测读数存放在运行目录的资产台账。

| 入口 | 用途 |
| --- | --- |
| `hardware.readonly --config <单机配置>` | 显式配置的地址发现、只读身份与设置、重连；不切换继电器 |
| `hardware.capture --resource <VISA SOCKET> --serial <主机序列号>` | 读取已绑定的 Pt100 测点，或未绑定设备的当前扫描列表；可通过 `--channels 101 201` 选择其中的通道 |

用项目 Python 的 `-m lab_control.instruments.devices.keithley_2701.hardware.capture` 调用采集入口。读取前核对槽位、每路功能、测量路径和返回格式，要求仪器处于支持的空闲接线状态。临时路由各通道，核对回复通道和单位。无论成功或失败均尝试恢复继电器和返回格式；有恢复错误时停止采集，按通信记录核查最终状态。

成功批次保留原始收发、初末快照、两卡逐路 CSV、可重新打开的标量帧和结构化摘要。Pt100 批次比对各路主继电器与感测继电器，以及温度模式的初末设置。CSV 保留功能槽位中对应的测点名称。直流电压批次另外比对量程模式、固定量程和积分时间。实际切换/接线后的稳定时间及外部精度须用已知标准源单独验收。
