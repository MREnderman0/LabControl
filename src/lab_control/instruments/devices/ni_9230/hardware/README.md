# NI 9230 实机验证

核对 CT12000L 接线，使用正式项目环境执行 `python -m lab_control.instruments.devices.ni_9230.hardware.verify --serial <八位十六进制模块序列号> --channels 1 2 3`。界面 CH1–CH3 对应模块 AI0–AI2。开始监测会向所选传感器提供 4 mA IEPE 激励。

1. 在项目进程锁和设备锁内枚举物理模块、核对型号与序列号，断开并重连，保存初始状态及灵敏度。
2. 从正式监测服务启动连续记录。稳定后读取至少五次。核对每次每个健康通道只有一个有符号加速度值，单位为 g，同时记录故障通道状态。
3. 停止监测，等待任务和文件写入收尾，重开记录逐项核对点数、通道、时间戳与状态。任一无效输入均不得以数值写入记录。
4. 现场复核等待稳定时停止、重新开始、按通道显示、开始及停止记录。冷启动试验须先将所选输入的 IEPE 激励设为 0 mA，核对驱动读回并记录断激励时长。保存从首个硬件扫描开始的原始样本，以便重算基线和各路就绪时刻。核对首个有效点出现在通过判据后。停止监测后应能再次正常打开设备。量值准确性由外部标准验证。

批次保存于正式运行目录 hardware-tests，包含 results.json、summary.json、record.md 和已保存单点记录的引用。
