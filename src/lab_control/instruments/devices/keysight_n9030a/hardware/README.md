# N9030A 只读测试

在正式运行目录中选择唯一的 LAN/VXI-11 端点，填入预期完整型号及序列号。通过项目 `verify-readonly` 入口指定 `--adapter keysight.n9030a`，使用独立批次目录。

1. 通过公共会话和真实设备进程锁读取身份与当前模式。状态读取保留面板的触发、扫描状态和格式。
2. 采集条件为 Swept SA 并已有有效 Trace 1。保存原始通信、初始和最终快照以及实际点数、物理单位和横轴范围。连续扫描时，现场可以预先选择单次扫描完成或暂停轨迹更新，便于对固定轨迹作比较。
3. 复核重连身份和最终状态。记录输入端的实际接线和已知信号条件；未接校准源时只能验证数据链路。查询失败、会话占用和条件不符也需保留批次。
