# R&S FSPN-26

## 能力与协议

`rs.fspn26` 属于 `phase_noise_analyzer`。设备管理页支持单次采集、连续采集和读取面板已有结果。每轮完成后自动记录并导出两张图，右侧并排列出仪器实际返回的各条迹线 Spot Noise 读数。

命令依据为主机用户手册 1179.4363.02 第 06 版，§5.4、§11.5.3、§11.7.1 及 §11.7.3。重点见第 99、368–371、459、465、471–472、476 页。[厂家手册](https://scdn.rohde-schwarz.com/ur/pws/dl_downloads/pdm/cl_manuals/user_manual/1179_4363_01/FSPN_UserManual_en_06.pdf)

## 连接与驱动

使用 LAN VISA 资源，复用公共组件 `rs-visa`。以 `*IDN?` 核对厂家、完整型号和资产序列号。测量载波相噪时，把已经在工作且符合输入规格的 DUT 射频输出接到前面板 RF Input，按手册 §4.1 在仪器上完成载波搜索与测量。

## 单位与限制

相噪谱沿用仪器各迹线独立的频偏（Hz）和相噪（dBc/Hz）。Allan 偏差直接取面板结果，横轴为 τ（s），纵轴为无量纲 ADEV。每轮记录的 `round-0001/` 内有 `phase_noise.csv` 和 `allan_deviation.csv`，同级原始记录保存身份、时间、设置和 Spot Noise。连续模式逐轮等待磁盘完成。

`phase_noise_round` 使用同步完成的单次测量，在当前相噪应用中补齐缺少的结果窗口。`phase_noise_display` 仅读已有结果，时间标为读取时间。传统 `trace` 请求保留首条有效相噪迹线的只读接口。载波搜索失败时保留上次数据的时间。

参数支持起止频偏、RBW 比例、互相关因子和 RF 衰减的部分更新；在自动衰减和手动衰减间切换时仅发送必要命令。当前分段手动配置下，全局 RBW 与互相关因子只显示。设置与曲线传输的依据见手册 §11.5–11.7。

## 测试入口与验证范围

[只读硬件计划](hardware/README.md) 使用正式会话与资产锁。软件回归在 `tests`，包含物理量、窗口选择、无效回包、配置变化与管理页单帧记录。实机逐台结果与通信记录存放在运行目录 `hardware-tests`。

固件 3.02SP1 的实机批次通过正式窗口核对两条相噪迹线、面板 Allan 偏差、Spot Noise 与双 CSV 逐点回读。主动单次测量在搜索失败时给出缺少载波的提示。

## 已知限制与待测

当前支持 ASCII 传输。有效载波下的新单次及连续多轮采集、参数写入的实机读回按资产批次独立验收。VCO 测试、AM 噪声和绝对精度未在此页面验收。

## 扩展与移除

型号命令和单位校验在本包维护。相噪管理页及指标处理复用公共逻辑。移除注册后保留已有历史记录。

已启用的相噪迹线均为零点时，软件读取相噪和频率状态寄存器，分别提示未找到待测载波或外部参考异常。
