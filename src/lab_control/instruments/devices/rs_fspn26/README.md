# R&S FSPN-26

## 能力与协议

`rs.fspn26` 属于 `phase_noise_analyzer`。通过设备管理页的“读取当前相噪曲线”保存一帧显示结果。仪器在当前窗口中返回偏频与相噪的交替数值，项目保留原始 Hz 坐标及 dBc/Hz 读数，离线使用公共的指定偏频相噪指标。

命令依据为主机用户手册 1179.4363.02 第 06 版，§5.4、§11.5.3、§11.7.1 及 §11.7.3。重点见第 99、368–371、459、465、471–472、476 页。[厂家手册](https://scdn.rohde-schwarz.com/ur/pws/dl_downloads/pdm/cl_manuals/user_manual/1179_4363_01/FSPN_UserManual_en_06.pdf)

## 连接与驱动

使用 LAN VISA 资源，复用公共组件 `rs-visa`。以 `*IDN?` 核对厂家、完整型号和资产序列号。测量载波相噪时，把已经在工作且符合输入规格的 DUT 射频输出接到前面板 RF Input，按手册 §4.1 在仪器上完成载波搜索与测量。

## 单位与限制

采集请求为 `AcquisitionRequest("trace", allow_setup=False)`。项目读取当前相噪应用中的 L(f) 图，优先选择显示顺序中第一个具备有效 PN 迹线的窗口，再取其首个启用的 PN 迹线。若显示其他测量、格式不受支持或没有有效点，界面显示原因。频偏应严格递增并大于零。

读回的是当前显示的已采集结果。确认测量时间、输入是否接通和仪器是否刚完成扫描，需要对照现场测量状态。该操作不会开启扫频或 VCO 电源。

## 测试入口与验证范围

[只读硬件计划](hardware/README.md) 使用正式会话与资产锁。软件回归在 `tests`，包含物理量、窗口选择、无效回包、配置变化与管理页单帧记录。实机逐台结果与通信记录存放在运行目录 `hardware-tests`。

通过 `run.bat` 在固件 3.02SP1 实机完成枚举、完整身份核对、项目会话连接、参数读取和重连。当前应用为 PNO，传输格式为 ASCII，相噪窗口的首条迹线已启用且结果类型为 PN。首轮读回点数为 0，有效相噪测量值仍待用载波补测。

## 已知限制与待测

目前支持 ASCII 迹线。更换应用、写入设置、VCO 测试、AM 噪声、稳定度、绝对精度和二进制传输需单独验证。

## 扩展与移除

型号命令和单位校验在本包维护。相噪管理页及指标处理复用公共逻辑。移除注册后保留已有历史记录。

已启用的相噪迹线均为零点时，软件读取相噪和频率状态寄存器，分别提示未找到待测载波或外部参考异常。
