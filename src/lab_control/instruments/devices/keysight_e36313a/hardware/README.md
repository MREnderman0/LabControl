# Keysight E36313A 实机计划

从正式工作区当前扫描结果选择电源，使用厂家、完整型号与实际序列号核对资产，分别验收每台电源。默认 VISA 资源由发现提供。

| 项目 | 验收方式 |
| --- | --- |
| 连接与重连 | 通过正常会话核对身份及各通道设定、输出开关读回 |
| 采集与保存 | 在电源监测页勾选 CH1–CH3，保存三组 V/A 读数并回读 |
| 状态复核 | 对照前后电压、电流设定及输出状态，排除测量噪声 |
| 写入与物理输出 | 本次只读。另行授权后，在已知负载和接线下备份、设置并恢复 |

通过 `run.bat --cli verify-readonly --help` 查看按资产执行的参数。通信记录、原始数据及摘要保存在个人运行目录。
